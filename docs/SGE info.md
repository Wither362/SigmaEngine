# SigmaEngine DOCS

SigmaEngine is a game engine (or tool engine) for the FX-CG50 / Prizm Calculators.

It's meant to be fairly similar to Unity's C# and MonoBehaviour style of coding, to make matters easier and fairly simple to understand and use.

It is entirely written in Python, corresponding to the specific MicroPython version, and it's meant to be executed with the ExtraPython/PythonExtra add-on for the CG50.

The short name for SigmaEngine is SGE, in case of this manual or code referring to it as SGE.
